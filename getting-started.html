Getting Started

Trudia Beta v0.2.1 is a Windows application. Download the installer and follow the steps below.

1. Download the Installer

Download Trudia-Setup-0.2.1.exe from the homepage.

2. Run the Installer

Double-click the downloaded file to start the installation.

Windows may show a security warning. Click Run to continue.

3. Follow the Installation Wizard

Choose the installation location (the default is fine for most users) and complete the setup.

4. Launch Trudia

After installation, open Trudia from the Start Menu or the desktop shortcut.

5. Choose a Database Location

On first launch, Trudia will ask where to create the database. The default location is recommended.

6. Create Your Admin Account

Enter your administrator details and click Register.

7. Initial Setup

Before using Trudia, you should:

  • Create tables
  • Create menu categories
  • Create menu items
  • Configure restaurant information (restaurant info is required for printing and checkout)
  • Set up receipt printer (optional)

Beta Notes
