Getting Started

Trudia Beta v0.2.0 is a portable Windows application and does not require installation.

1. Download the Beta

Download the Trudia Beta ZIP file from the homepage.

2. Extract the ZIP File

Right-click the ZIP file and choose "Extract All..." or use your preferred extraction tool.

3. Run apptrudia.exe

Open the extracted folder, find and launch apptrudia.exe.

Windows may show a security warning for unsigned applications. If prompted, select "More Info" and then "Run Anyway".

4. Choose a Database Location

When Trudia starts for the first time, you'll be asked where to create the database. The default location is recommended for most users.

5. Create Your First Admin Account

Enter your administrator details and click Register.

6. Initial Setup

Before testing, you'll likely want to:

  • Create tables
  • Create menu categories
  • Create menu items
  • Configure restaurant information
  • Configure receipt printer settings (optional). Restaurant information are required in order to print receipts.
